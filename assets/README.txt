DiArt Visual Assets v2

12 фирменных пинов созданы заново как отдельные SVG.
Обрезка исходного изображения не использовалась.

Преимущества:
- прозрачный фон;
- масштабирование без потери качества;
- единая геометрия;
- отдельный файл для каждого цветотипа;
- готово для DiArt Engine, SVG-паспорта и круговой диаграммы.

Важно:
Форма, цвет и внутренний символ каждого пина зафиксированы.
