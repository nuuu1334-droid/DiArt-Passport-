# DiArt Botanical Branches

12 адаптивных рустикальных веточек для цветотипов DiArt.

## Структура
- `svg/` — векторные версии для Passport Builder.
- `png/` — растровые превью.
- `branches.manifest.json` — соответствие цветотипа и файла.

## Ключи цветотипов
light_spring, warm_spring, bright_spring,
light_summer, soft_summer, true_summer,
soft_autumn, true_autumn, deep_autumn,
bright_winter, true_winter, deep_winter.

## Использование
По ключу цветотипа берите путь из `branches.manifest.json`
и подставляйте SVG в блок `important_note`.
